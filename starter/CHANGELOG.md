# Changelog

## 1.0.0 — 2026-09-19

- Public v2 schema with explicit field projection and safe HTML rendering.
- Three visual directions and optional About/Hello pages.
- Portable ZIP kit, editable source, MIT license, deployment workflow and guide.
- Optional visible attribution and versioned provenance.
- Root and repository-subpath support; no runtime JavaScript or analytics.

Private builder projects use their own version 1 schema. Existing public v1
snapshot links remain supported by the website's legacy viewer.
