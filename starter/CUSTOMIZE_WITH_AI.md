# Customize with an AI assistant

You can give the following prompt to a coding assistant alongside this kit.
Share only files you intend the assistant to read; your private project and
résumé are not needed to customize the public site.

> Work within this Buildmine starter. Read README.md, DEPLOY.md, site.json,
> styles.css, core.mjs, and generate.mjs. Preserve my factual public copy; ask
> before inventing claims, clients, results, qualifications, or testimonials.
> Make the design accessible and responsive. Keep static HTML output, local
> assets, relative links working at both a domain root and a repository path,
> and no paid services or analytics. Edit the source, not just generated files.
> Keep the MIT notice; visible Buildmine attribution is optional. Run the tests,
> regenerate site/, and check every internal link. Explain exactly what changed
> and how I can publish it using DEPLOY.md. Do not publish private project files,
> résumés, secrets, or information I haven't chosen for the public site.

Describe the specific visual change you want below that prompt. For generated
code, review the diff and preview locally before replacing your live site.
