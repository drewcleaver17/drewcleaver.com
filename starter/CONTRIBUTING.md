# Contributing

Useful small contributions include clearer setup instructions, reproducible
accessibility fixes, improved tests, and additional fictional examples. Submit
an issue or PR to the parent repository, noting that it concerns `starter/`.
Keep PRs scoped to this directory unless they also affect the Buildmine UI.

Run `node --test core.test.mjs` and `node generate.mjs` in this directory.
Use fictional data in reports. Never attach a real résumé, private project,
access token, or a preview URL containing someone else's personal details.
For a sensitive report, use Drew's public contact route rather than an issue:
https://drewcleaver.com/hello/.

Optional showcase: send Drew your already-public site URL and explicitly say
whether your name and link may appear in the showcase. Nothing is listed
automatically. Removal requests use the same contact route. No adoption or
completion statistics are inferred from downloads, copies, or preview links.
