# Tesloco / Spec Tesla Cup preservation

Requested by Drew September 19, 2026 for memory and portfolio use.

- `/tesloco/`: surviving public `https://tesloco.wordpress.com/`, retrieved September 19, 2026, plus its three public content pages.
- `/specteslacup/`: latest successful homepage capture recovered, February 8, 2026, and first listed homepage capture, October 17, 2022. Additional public content pages use individually dated successful captures. No claim to a complete Shopify export, every historic version, or original revision dates.
- Source URLs, page SHA-256 values, asset provenance and missing assets are in `public/archives/manifest.json`. The generator is `scripts/preserve-tesla-sites.py`; it expects a separately retained recovery folder.
- Source commercial language and names are reproduced as historical content. Wrapper warns that plans, prices and relationships are not current claims and that milestones may not have happened. No billing details or private account correspondence are published.
- Preserved HTML has no original scripts or active forms. CSP restricts resource loads to local assets; old checkout/account/booking destinations are inactive. Embeds are replaced by native YouTube links where video IDs survive. Locally recovered page links work inside the archive. Missing internal destinations are inactive.
- Styling is original with narrow static-replay repairs for lazy images, slideshows, disabled widgets and mobile presentation. It is an archival replay, not the functioning original e-commerce application or a pixel-perfect screen capture.
- Git repository owns website assets and preserved HTML; no parallel Library copy of repository files is required. Raw recovered public HTML remains in a separate backup for future restoration.
