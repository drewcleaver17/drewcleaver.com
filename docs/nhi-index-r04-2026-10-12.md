## Editorial inspection

Selection lens: explanatory changes in knowledge, capability, institutions/power, influential controversies, or essential narrative bridges. Existing sourced chapters already cover human origins, mathematics and astronomy, printing, scientific instruments, computation, medicine, space exploration and the modern institutional record. Twenty-four regional additions had just addressed Egypt, Maya/Yucatán, Mexica/Mesoamerica and Brazil/Amazonia. No additional bridge was necessary to understand the current curated scope; the larger missing foundations need a separate bounded research pass.

The collection is uneven: Intelligence & secrecy appears in 128 records, Science & invention in 81, UFO reports & disclosure in 69, Space & SETI in 63, and Ancient societies & archaeology in 22 (topic memberships overlap). A prominent scope note acknowledges this modern-science/U.S.-institution concentration. No comprehensive-world-history claim, causal chain toward non-human intelligence, certainty score, credential, team, or curriculum endorsement is introduced.

Four starter stops reuse existing source-backed events and their evidence notes. Ten existing chapters receive inquiry questions and visible stable chapter links; summaries remain separate from event counts. Citation guidance credits Drew Cleaver as compiler/editor and encourages original-source citation. Evidence labels and source inspection/access notes remain authoritative. Chapter example links provide the source-backed path into context without claiming that chronological adjacency establishes influence.

### Editorial walkthroughs (inspection, not user testing)

- Teacher: start with an era; discuss a chapter question; compare what an event establishes and does not establish; follow a source or a profile’s selected work. Printing opens visible event evidence notes and retains source URLs.
- Friend: understand the title and four-stop orientation; search an ordinary term; share an event link or the exact filtered view.
- Journalist: distinguish incident, publication and disclosure dates; follow a cited passage and its provenance/inspection limit; cite the original rather than treating the Index as corroboration.
- Curious skeptic: examine claim-specific limits without accepting extraordinary origins. Regional engineering and astronomy remain human achievements.
- Committed UFO believer: retain access to substantial encounter testimony, investigations and disputed interpretations while distinguishing testimony from authenticated physical evidence. No agreement with the editor’s worldview is required.

## UX audit to change

| Initial friction | Implemented response |
|---|---|
| Refinements behind a closed disclosure | All filter groups openly displayed; no Advanced panel or filter drawer |
| Choices hidden inside dropdowns | Labeled native radio choices generated from every existing option; single-selection semantics retained |
| 528 entities plus legacy names and 1,357 year choices | Complete labeled catalogs, no clipped/horizontal option rows or choices dropped at zero results |
| Readers return to page top | Sticky desktop workspace; sticky search/status/Adjust filters on narrow or short screens |
| Active constraints difficult to scan | Individual-removal chips, applied-view/order summary, accurate counts, clear search and explicit clear-search-and-all-filters actions |
| Replacing result containers can detach focused nodes and disrupt position | Reuse cards and only move nodes whose container/order changes; retain a visible card offset or nearest remaining chronological neighbor |
| Copy view behavior hard to find | Persistent copy-view action with clipboard success and browser-address fallback |
| Filtered deep link can exclude a target | Existing explicit Reveal remains; intentional chapter/event scope changes now announce the changed view |
| People and institutional choices are dropdown-only | Their existing role/type/domain/arrangement/evidence/order options are also exposed; existing independent URL/filter models retained |

Timeline choices remain one per group; separate groups narrow together, and all search terms must match. Context is now a visible optional control rather than an inaccessible checkbox. View selection still resets that optional context flag. Search remains separate from named-entity selection. Unknown values gracefully use valid defaults. Browser back/forward restores URL state. No available option disappears because its result count is zero.

Desktop sticky workspace applies from **1100 CSS px width and 760 px height**. Search, count, selected constraints, resets and appearance remain at its top. The exceptionally long full option workspace scrolls below an explicit instruction, with a focusable labeled region and native keyboard controls. There is no secondary nested catalog scroller in that layout. On narrow/tablet/short screens the full form remains inline. Only the exceptionally long name and year catalogs use apparent focusable scrolling at **65svh**, with at least an 18rem catalog area. They are openly displayed, not hidden panels.

The narrow/short sticky bar retains search, result count, applied summary, clear and copy, plus an **Adjust filters** anchor. Adjust saves the visible record; **Return to reading** restores that record or the nearest remaining chronological record. The bar is compact in short landscape viewports. CSS scroll margins account for it. This compromise avoids pinning thousands of choices above the content.

Refinement preserves focus on the used control. Desktop/persistent-bar refinement compensates for a visible record’s offset; if excluded, it uses the nearest retained chronological entry. This algorithm is intentionally small and uses current geometry, not a new scroll-history framework. Changing a view intentionally starts a reading path; Back/forward may intentionally follow a saved hash. These navigation actions are distinct from refining the current feed.

## Appearance

Default remains **light**; there was no existing system-theme preference system. Explicit Light/Dark green controls synchronize and save `nhi.reading.appearance` locally. A scoped head script restores a valid preference before paint; storage failures preserve usable content. Other pages retain their existing palette. No system setting is silently introduced.

Dark tokens: canvas `#082B24`, surface `#103B31`, raised green `#17473A`, warm text `#F3EFE5`, muted text `#C3D3C7`, control background `#0C3229`, selected pale-green accent `#C7D8A9`, focus `#F1C982`. Measured primary/muted text pairs exceed 4.5:1 on all four green surfaces; borders exceed 3:1 on the filter surface. Native checked states, labels, underline and focus accompany color. Photographs are not inverted. Print forces light/dark-text tokens regardless of the stored appearance and restores screen disclosure state afterward.

## Verification and limits

Required validation, build/release/privacy checks and original model/DOM suites are run alongside nine new interaction/palette checks. These cover every exposed option, multi-group semantics, single history update per choice, focus, unknown/default restoration, counts, empty recovery, distinct clears, simulated geometry compensation, explicit return to a filtered reading location, synchronized theme/persistence/blocked storage, pre-paint restoration, filtered-copy fallback, and print disclosure restoration.

Responsive source inspection covers **320, 390, 768, 1440 px**, short landscape and a 200%-zoom-equivalent narrow layout. Native browser geometry, actual 200% browser zoom, onscreen keyboard, touch scrolling and screen-reader behavior cannot be claimed: the supported browser controller is unavailable in this environment. DOM geometry tests simulate measurements and do not establish actual viewport layout. No formal user testing or full accessibility-conformance claim is made. These remain release limitations, not disguised passes.
