# People portrait credits

Each image is governed by its own reuse declaration in `attribution.json`; repository code licensing does not replace image licenses. Sources are Wikimedia Commons file-description pages inspected on October 12, 2026. CC BY-SA image crops remain offered under the source image’s listed license. Original public-domain bases, creator credits, crop notes and verification logs are recorded per image.

The directory serves these optimized local 320 × 400 WebP files. Historical artwork and later depictions must retain their labels; a portrait is not evidence for the subject’s claims. A neutral fallback is used when a suitable reusable image was not selected.
